## Getting Started

### Requirements

- Node.js
- npm

### Installation

```bash
git clone https://github.com/yasirabedrabbu/Portfolio-yasirabedrabbu.git

cd Portfolio-yasirabedrabbu

npm install
```

### Run locally

```bash
npm run dev
```

Visit `http://localhost:3000`.

### Production

```bash
npm run build
npm run start
```

### Lint

```bash
npm run lint
```
